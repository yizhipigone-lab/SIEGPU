## 图 1：资金流转全景（业务操作 → 四大资金池 → 资金运用）

```mermaid
flowchart TB
    subgraph SRC["① 资金来源（入池）"]
        S1["银行借款 → BANK ✅"]
        S2["金租放款 → LEASING ✅"]
        S3["自有期初 / 记一笔 → OWN"]
        S4["收款(租金) → OWN ⚠️"]
    end

    subgraph POOLS["② 四大资金池（capital_transactions.pool）"]
        OWN["OWN 自有资金池"]
        LEASING["LEASING 金租池"]
        BANK["BANK 银行池"]
        PREPAY["PREPAY 预付挂账池"]
    end

    subgraph ACT["③ 资金运用（出池 / 业务动作）"]
        A1["付款 disburse<br/>拆分✅ / 非拆分不校验⚠️"]
        A2["预付 record_prepayment → PREPAY ✅"]
        A3["预付退回 refund → 现金 ✅<br/>台账不更新 🔴"]
        A4["预付核销 offset → PREPAY OUT ✅<br/>台账不更新 🔴"]
        A5["金租直付 负债IN+代付OUT 净0 ✅<br/>科目未实现 ⚠️"]
        A6["置换归还 回填bank_id ✅"]
        A7["还银行 repay_bank → BANK OUT ✅"]
        A8["项目调配 allocate 净0 ⚠️"]
        A9["核销汇兑损益 → OWN ⚠️"]
        A10["确认还款 confirm_repayment<br/>❌ 无流水 🔴"]
        A11["金租利息<br/>❌ 无流水 🔴"]
    end

    S1 --> BANK
    S2 --> LEASING
    S3 --> OWN
    S4 --> OWN
    BANK --> A1
    BANK --> A2
    LEASING --> A1
    LEASING --> A5
    OWN --> A1
    OWN --> A8
    OWN --> A9
    A2 --> PREPAY
    PREPAY --> A3
    PREPAY --> A4
    A6 -.-> BANK
    A6 -.-> OWN
    BANK --> A7

    style A10 fill:#fdeaea,stroke:#c0392b
    style A11 fill:#fdeaea,stroke:#c0392b

```
