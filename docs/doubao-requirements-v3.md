第一章 项目概述
1.1 项目背景
随着公司算力租赁、算力转售、算力自营业务规模快速扩张，金融租赁（直租 / 售后回租）已成为核心资金来源，资金端精细化管控需求显著提升，现有管理模式存在以下核心痛点：
业财数据脱节，业务操作与财务核算不同步，收入确认、成本归集口径不一致；
算力设备交付链路长、节点多，单台设备状态、资产权属、保险管控难以精细化跟踪；
金租项目资金监管规则复杂，季度还款与月度最低留存额依赖人工计算，监管账户余额管控易出现合规风险；
直租与售后回租模式下，采购预付款的处理逻辑差异大，人工区分易出错，资金流向追溯困难；
采购预付款资金需求缺乏前瞻性测算，存量资金缺口无法提前预警，易导致采购计划延误；
收入核算模式依赖人工判断，合规性风险高；融资全流程管理分散，资金成本测算与毛利核算颗粒度不足。
为实现算力业务全流程数字化管控、金租业务合规化资金管理、资金缺口前瞻性预警，启动 SIEGPU ERP 系统 建设，打造覆盖业务、资金、财务、资产的全链路业财一体化运营平台，并与 Oracle EBS 财务系统深度对接。
1.2 建设目标
单台设备精细化管控：以单台设备为最小交付与资产单元，全生命周期跟踪状态、成本、折旧、保险、计费；支持多台设备组合为批次批量作业。
金租业务全模式适配：完整支持金融租赁「直租」「售后回租」两种合作模式，适配不同模式下的采购预付款处理、放款还款、资产权属、核算规则。
监管账户合规管控：按金租资金监管计划自动计算季度还款对应的月度最低留存额，租金到账后自动校验监管账户余额，确保合规，超限资金可灵活划转。
资金池智能预测：基于采购预付款计划、融资还款计划、租金收入计划、运营支出计划，自动测算未来多期资金余额，预判资金缺口，触发融资补充预警。
全流程闭环管控：以「项目编号」为主线，贯穿采购、交付、资产、销售、融资、资金全链路，实现端到端数字化管理。
业财一体化核算：内置智能收入判定引擎，自动匹配核算规则；业务单据审核后自动同步 Oracle EBS 生成凭证，保障合规与数据一致。
精细化毛利管理：按项目、合同、单台设备维度精准归集全成本（采购 + 融资 + 运营 + 税费 + 保险），自动计算毛利，支撑经营决策。
合规审计可追溯：全流程操作留痕，资金流向、收入判定、数据变更、接口日志完整留存，满足内外部审计要求。
1.3 系统定位
SIEGPU ERP 是面向算力业务的前端业务运营与业财一体化中台，承载业务操作、过程管控、资金预测、数据统计；Oracle EBS 作为后台财务总账系统，承接核算凭证与科目余额；两者通过标准 API 双向打通，实现业务发起、财务核算、数据对账全链路自动化。

2.2 管理单元定义
最小单元：单台设备
每台算力设备为最小交付、资产、计费单元，分配唯一设备 SN 编码，全流程独立跟踪状态、成本、折旧与收入。
所有交付节点、资产转固、保险投保、计费启动均支持单台粒度操作与数据查询。
批量单元：设备批次
支持从单台设备中选择任意数量组合为一个批次，生成全系统唯一批次编号。
批次用于批量采购、批量到货、批量验收、批量转固、批量投保、批量放款等批量作业场景。
批次下挂载所有归属设备明细，支持批次汇总统计与单台穿透查询；同一台设备仅能归属一个批次。
2.3 金租业务核心资金规则
2.3.1 监管账户管控规则
金租项目设立专属监管账户，租金收入统一归集至监管账户，还款资金从监管账户划出。
还款方式：按季度还款，每季度支付约定的本金 + 利息。
月度最低留存额规则：每月监管账户余额不得低于季度还款金额 / 3，确保季度还款资金储备合规。
资金划转规则：收到租金收入后，系统自动校验监管账户余额；余额高于月度最低留存额的部分，可划转至公司普通资金池；余额低于最低留存额时触发补足提醒。
2.3.2 采购预付款与金租模式适配规则
通用规则：设备采购需向供应商预付订货款，预付款从公司普通资金池支付，关联对应采购批次与项目。
直租模式处理：
金租公司作为设备买方向供应商支付全额货款；我方前期支付的预付款，根据下一批订货资金需求情况，由供应商退回至公司普通资金池，或结转至下一批次采购预付款。
售后回租模式处理：
设备由我方先行采购并确权，金租公司支付设备受让款后，设备权属转移；我方前期支付的预付款无需退回，继续作为采购资金流转，后续按期向金租支付租金。
2.4 核心核算模式
系统基于合同关键条款自动判定核算路径，判定依据全程留痕可审计：
总额法：企业拥有自主定价权、承担存货风险与交付主要责任，全额确认营业收入，采购成本全额结转营业成本。
净额法：企业无定价权、不承担存货风险，仅作为代理人角色，仅按服务费差价确认营业收入。
经营租赁法：自有资产对外出租，资产保留在资产负债表内，按期确认租金收入，匹配资产折旧成本。
金租核算规则：直租与售后回租按租赁准则区分表内 / 表外处理，租金支出按融资成本核算，匹配项目成本归集。
2.5 核心业务主线
以项目编号作为唯一核心标识，贯穿项目立项→采购下单→预付款支付→批次组合→单台交付→资产确权→金租放款→销售签约→租金收入→监管账户管控→还款付息→成本归集→结项复盘全流程；所有业务单据强制关联项目号，所有设备强制关联批次号与项目号，实现项目 - 批次 - 单台三级数据聚合与全周期追溯。
第三章 系统功能需求
3.1 项目管理
3.1.1 项目立项管理
支持算力项目立项申请与多级审核，生成全系统唯一项目编号与项目名称。
立项信息包含：项目编号、项目名称、业务类型、租赁模式（自有 / 直租 / 回租）、项目负责人、服务周期、预算总额、融资方案、备注等。
支持主项目下设子项目，层级关系清晰，可按层级汇总数据。
项目状态管理：筹备中、执行中、已结项、已终止，状态变更全程留痕。
项目生效后，全系统所有业务单据必须关联对应项目号，未关联项目号的单据无法提交审核。
3.1.2 项目全景视图
单项目维度聚合展示全链路数据：关联采购合同、销售合同、批次清单、设备交付进度、资产清单、融资方案、监管账户余额、收付款记录、收入确认、成本归集、累计毛利、资金预测结果。
支持从项目总览穿透到批次、穿透到单台设备详情，实现三级链路追溯。
3.1.3 项目预算管控
维护项目采购预算、预付款额度、费用预算、融资额度预算。
采购下单、预付款支付、付款申请、费用支出时自动校验预算额度，超预算触发预警或审批拦截。
支持预算调整申请与审批，调整记录全程留痕。
3.2 主数据管理
3.2.1 客户档案管理
维护客户工商信息、联系人、银行账户、信用等级、合作资质。
支持客户标签分类、多条件筛选，新建销售合同时直接下拉引用。
数据审核通过后自动同步至 Oracle EBS 客户主数据，保持两端口径一致。
3.2.2 产品与设备型号管理
维护 GPU 机型、服务器配置、计费模式（按时 / 天 / 月）、基准单价。
标记资源属性：自购资产、金租资产、转售资源，匹配对应核算规则。
关联资产折旧规则、单位运营成本参数，为测算模型与成本核算提供基础数据源。
3.2.3 供应商管理
维护硬件供应商、上游算力厂商、保险公司、金融机构档案。
支持供应商分类、资质管理、评级管理；金租机构单独标记并维护合作模式（直租 / 回租）。
数据审核通过后自动同步至 Oracle EBS 供应商主数据。
3.2.4 银行账户管理
账户分类管理：普通结算账户、金租监管账户，分别标记归属项目与金租机构。
维护账户开户行、账号、币种、用途、监管规则等信息。
关联资金池与收付款模块，支持按账户维度统计流水与余额。
3.2.5 币种与汇率管理
支持多币种档案维护，默认本位币为人民币。
汇率体系：支持维护记账汇率、发票汇率、结算汇率三类汇率，支持按月 / 按日更新。
汇兑损益规则配置：定义汇率差异入账科目为「财务费用 - 汇兑损益」，自动匹配 Oracle EBS 科目映射。
所有业务单据均支持登记币种，默认带出人民币，可手动切换。
3.2.6 基础规则配置
设备状态规则、批次编码规则、保险险种费率、资产分类与折旧规则。
金租规则配置：监管账户留存规则、直租 / 回租预付款处理规则、还款周期参数。
单据编号规则、审批流程配置、数据字典维护。
3.3 采购与付款管理
3.3.1 采购合同管理
支持三类采购合同：算力硬件采购合同、上游算力资源采购合同、运维 / 技术服务采购合同。
合同强制关联项目号、供应商、币种、金租模式（自有 / 直租 / 回租），成本自动归集至对应项目。
采购明细支持「按台录入」与「按批次录入」两种模式，每行明细对应设备型号、数量、单价、约定交付时间；后续可匹配具体设备 SN 与批次号。
支持单份采购合同拆分多个交付批次，每个批次独立设置交付时间、验收标准、付款节点、预付款比例。
维护合同核心条款：定价规则、质保条款、违约条款、运费与保险承担方、预付款比例与退款条件。
合同变更管理：支持金额、数量、交付周期、付款条款等变更，生成正式变更单，记录变更前后数据、原因、生效时间、审批人，全程留痕；变更审核通过后自动更新对应批次、应付计划、预付款计划，同步 Oracle EBS 采购订单变更。
合同终止管理：支持部分终止、全部终止，登记终止原因、结算方式、违约金；自动生成终止结算单，联动应付调整、退货流程、预付款清算，同步 Oracle EBS 关闭对应采购订单。
合同详情页聚合展示批次清单、设备交付进度、验收记录、预付款记录、采购发票、付款记录、变更 / 终止记录、电子合同附件。
合同审核生效后，自动同步 Oracle EBS 采购模块，生成正式采购订单与应付计划。
3.3.2 预付款管理
预付款申请：基于采购合同约定的预付款比例发起申请，关联对应批次、项目、金租模式。
预付款支付：审核通过后从普通资金池支付，登记支付日期、金额、账户、币种，上传付款回单，同步扣减资金池余额。
金租模式适配处理：
直租模式：金租放款到账且设备确权后，系统自动生成预付款退回待办，支持「全额退回」「结转下一批采购」两种处理方式；退回资金原路返回普通资金池，结转则自动关联下一批次采购订单。
售后回租模式：金租支付设备受让款到账后，预付款无需退回，系统自动标记预付款已结转，纳入项目采购成本归集。
预付款核销：后续到票或结算时，将预付款核销对应应付账款，精准归集批次与单台设备成本。
预付款台账：按供应商、合同、批次、项目、金租模式查询全量预付款明细，展示未核销余额、预计退回 / 结转时间。
3.3.3 付款管理
采用「付款申请 — 付款登记 — 付款核销」三重管控模式。
付款申请基于采购合同约定的付款节点（到货、验收、质保）发起，可关联对应批次、单台设备与发票，自动扣减对应预付款。
付款登记支持多币种结算，录入结算币种、结算汇率、实际支付本位币金额，上传银行回单凭证。
付款核销支持一笔付款核销多合同 / 多批次 / 多台设备，也支持多笔付款核销同一批次 / 单台设备，精准归集每台设备的采购成本。
付款核销时，系统自动对比发票汇率与结算汇率，计算汇兑损益金额，按成本占比分摊至对应设备。
提供付款台账，按供应商、合同、批次、设备、项目、时间维度查询全量付款明细，支持导出。
付款核销完成后，同步 Oracle EBS 应付模块，自动生成付款凭证与汇兑损益凭证。
3.3.4 采购发票管理
支持多币种发票登记，录入发票币种、发票汇率、原币金额、本位币金额、税额。
支持 OCR 识别快速录入，可关联对应采购合同、交付批次、单台设备、项目号。
进项税额独立核算，匹配总额法 / 净额法下的税务处理规则。
支持发票认证、抵扣、红冲全流程管理，红字发票对应退货、折让场景，自动冲减应付与设备成本。
发票信息同步 Oracle EBS 应付发票模块。
3.3.5 采购退货管理
支持单台设备退货、批量退货两种模式，可由到货不合格、压测不通过、合同终止等场景发起退货申请，关联原批次、原设备 SN、原采购订单、项目号。
退货全流程：退货申请→出库确认→供应商收货→红字发票→退款核销 / 预付款冲回。
财务联动：退货审核通过后自动冲减对应设备的采购成本；对应资产未转固则冲减在途物资，已转固则触发资产减少与折旧冲回；已支付预付款的自动生成预付款追回待办。
对应供应商退款登记与核销，同步冲减应付账款。
退货单、红字发票同步 Oracle EBS 采购与应付模块，自动生成红字入库与应付凭证。
3.4 设备与批次全生命周期管理
以单台设备为最小交付与资产单元，支持组合为批次进行批量作业；全节点状态流转自动触发对应业务动作与财务处理。
3.4.1 设备档案管理
每台设备生成唯一设备 SN 编码，强制关联设备型号、所属批次号、所属项目号、采购合同号、金租模式。
设备档案核心信息：设备 SN、设备型号、硬件配置、采购原值、预付款金额、供应商、批次号、项目号、金租模式、当前状态、资产编号、投保信息、对应销售合同、计费信息。
支持批量导入设备清单，自动生成设备档案；支持单台新增与编辑。
支持按批次、项目、型号、状态、金租模式多维度筛选查询设备清单。
3.4.2 批次管理
支持从待分组设备中选择任意数量设备组合生成批次，分配唯一批次编号，关联采购合同与项目。
批次信息包含：批次号、批次名称、设备型号、设备数量、设备清单、采购合同号、项目号、金租模式、当前整体状态、预付款比例。
支持批次内设备的新增、移出（仅未进入关键节点前可调整），调整记录全程留痕。
支持按批次批量执行节点操作，操作后批量更新批次内所有设备状态；也支持单台设备单独推进节点。
批次全景视图：展示批次整体进度、设备明细状态、采购信息、物流信息、预付款情况、成本汇总、关联资产、对应销售合同、金租放款进度。
3.4.3 设备全节点状态管控
单台设备全流程 7 个标准节点，支持上传验收报告、物流单、压测报告等附件，状态变更全程留痕：
订货：设备已下达采购订单，归属对应批次；自动触发预付款申请提醒，生成运输保险投保待办。
在途：设备发出进入运输阶段，关联对应运输保单，跟踪物流信息，保险责任自动生效。
到货：设备送达现场，登记到货时间、实收数量，生成到货验收单，触发暂估入库。
己方压测：到货后硬件性能与稳定性压测，记录单台压测结果；不合格自动触发单台退换货流程。
上架：压测通过后正式上架部署；自动触发固定资产转固（自有 / 回租模式按规则确权），按单台设备生成资产卡片，同步 Oracle EBS 固定资产模块，设备计入「可用算力资源池」。
客户压测：交付客户进行上线前验证，记录单台客户压测结果与问题整改。
点亮验收：客户正式验收通过，单台设备交付完成；同步触发四类业务动作：
销售端：对应销售合同该台设备正式开始计费，作为单台收入确认起始时点；
财务端：触发财产一切险投保，资产进入运营期，开始计提折旧；
融资端：对应金租项目的设备放款条件达成，达到批次放款阈值时自动触发放款申请流程；
资金端：更新资金预测模型的设备投产与收入流入节点。
3.4.4 保险管理
险种基础配置：货物运输险、财产一切险等险种的费率、保额规则、承保公司配置。
自动投保触发：
批次内设备进入「在途」状态：自动推送投保提醒，按批次设备总价值自动计算保费，生成运输险投保单，保费可按设备价值占比分摊至单台设备成本；
单台设备完成「点亮验收」：自动推送财产一切险投保提醒，绑定对应资产卡片，保费按规则计入资产原值或长期待摊费用。
保单全生命周期管理：保单信息登记、保费摊销、到期续保提醒、理赔记录，支持按单台设备、批次、项目归集保费成本。
保费核算数据同步 Oracle EBS 总账，自动生成对应入账凭证。
3.5 销售合同与收入管理
3.5.1 销售合同管理
合同强制关联项目号、客户、币种、金租模式，收入自动归集至对应项目。
支持单份销售合同拆分多个交付批次，批次下挂载具体设备清单，按单台设备点亮验收时间逐台启动计费。
维护合同核心条款：服务周期、计费规则、账期、收付款计划、租金回款账户（监管账户 / 普通账户）。
智能判定关键条款录入：必填定价权归属、存货风险承担方、主要责任人认定三项信息，作为核算路径判定依据。
合同变更管理：支持金额、周期、服务内容、计费规则、设备清单等变更，生成变更单留存审批痕迹；变更生效后自动调整收入计划、应收余额，同步 Oracle EBS 应收单据调整。
合同终止管理：支持提前终止，登记终止原因、结算金额、违约金；自动生成终止结算单，对应收入冲回、应收调整，联动算力资源释放。
合同详情页聚合展示交付批次清单、单台设备交付进度、收款记录、发票记录、收入确认记录、电子附件、EBS 同步状态。
3.5.2 收入核算路径自动判定引擎
基于合同录入的定价权、存货风险、主要责任人三项条款，系统自动推荐或强制锁定核算路径（总额法 / 净额法 / 经营租赁）。
判定规则：
无定价权、不承担存货风险：自动判定净额法，仅确认服务费差价收入；
有自主定价权、承担存货与交付风险：自动判定总额法，全额确认营收；
自购资产对外出租、资产权属保留：自动判定经营租赁，按期确认租金收入。
判定结果与判定依据全程留痕，可追溯审计，防范「总额法滥用」监管风险。
3.5.3 收入确认管理
严格遵循权责发生制，与开票、收款环节完全解耦，支持「先开票后确认收入」「先确认收入后开票」两类场景。
单台设备完成点亮验收后，系统自动按该设备对应金额与计费周期，按期生成收入确认草稿，人工审核后生效。
支持按项目、按批次、按单台设备独立确认收入，自动匹配对应折旧、保险、运维、融资成本，实现收入成本配比。
支持外币收入折算，汇率差异计入汇兑损益。
收入确认单审核通过后，同步 Oracle EBS 应收模块与总账，按判定的核算模式自动生成收入凭证。
3.6 项目测算中心
3.6.1 算力项目利润测算模型
以项目为单位录入基础参数：合同总收入、单台设备采购成本、预付款比例、运输费、保险费、运维 / 电费 / 带宽等运营成本、税费率、折现率、残值率。
支持按批次、按单台设备维度录入成本数据，自动汇总至项目全周期。
全周期利润测算：自动计算项目全生命周期总收入、总成本（采购 + 融资利息 + 运维 + 税费 + 保险 + 资金占用成本）、毛利额、净利润、IRR、静态 / 动态投资回收期。
年度维度拆分：按自然年度拆分收入、成本、利润，匹配年度预算与考核口径。
残值测算：按单台设备分别设定残值率与处置费率，自动计算期末资产残值与处置收益，纳入全周期利润。
多版本测算管理：支持多方案测算对比，定稿版本可一键同步至对应项目，作为项目立项与考核基准。
支持预算与实际对比：自动抓取项目实际发生的收入、成本、费用，实时对比预算毛利与实际毛利差异。
3.6.2 资金成本测算工具
核心参数配置：融资金额、年利率、融资期限、放款日期、手续费率、还款周期（按季 / 按月）。
还款方式切换：支持等额本金、等额本息两种主流还款方式。
支持按批次、按设备放款分别测算资金成本，自动汇总项目综合融资成本。
监管账户资金占用成本测算：自动计算月度最低留存额对应的资金占用成本，纳入项目综合资金成本。
自动生成全周期还款计划表，逐期展示应还本金、应还利息、剩余本金、当期资金成本、月度最低留存额。
自动计算含手续费的实际年化利率，为融资方案比选提供依据。
测算结果可一键同步至对应融资项目台账与资金预测模型。
3.7 融资与资金管理
3.7.1 融资项目落地跟踪
分类管理：金融租赁（直租 / 售后回租）、银行流动资金贷款、项目贷款等全类型融资。
每笔融资绑定对应项目，资金成本精准归集至项目，可分摊至批次与单台设备。
全流程节点跟踪：覆盖申请→尽调→审批→签约→分批放款全链路，每个节点记录进度、提交材料、对接人、预计完成时间。
支持按设备批次拆分放款计划，每个批次对应独立放款金额、放款条件（如批次设备点亮验收）。
直租 / 回租模式标记：选择对应模式后自动匹配预付款处理规则、监管账户规则、核算规则。
进度看板：直观展示所有金租、银行贷款项目的当前阶段、各批次放款状态、滞塞节点。
融资申请材料、审批文件、合同文本统一上传归档。
3.7.2 监管账户管理
监管账户台账：每个金租项目对应专属监管账户，展示账户余额、累计流入、累计流出、绑定项目、金租机构、季度还款计划。
月度最低留存额自动计算：根据季度还款计划，自动计算每月最低留存额 = 季度还款金额 / 3，按月度更新基准值。
到账自动校验：租金收入划入监管账户后，系统自动校验账户余额；余额低于最低留存额时触发预警，提醒补足资金；余额高于最低留存额的部分，支持发起划转申请，转入普通资金池。
资金划转审批：超限资金划转需走审批流程，登记划转金额、日期、目标账户，全程留痕。
监管账户流水独立台账，与普通资金池分账核算，满足金租监管要求。
3.7.3 放款还款跟进表
放款台账：按批次登记实际放款日、放款金额、到账账户（监管账户 / 普通账户），关联对应融资项目与设备批次，自动同步资金池；放款成本可分摊至单台设备。
直租模式：放款定向支付供应商，同步核销预付款并触发退款流程；
售后回租模式：放款进入公司普通资金池，同步确认长期应付款。
还款计划管理：支持按单笔放款生成独立还款计划，或按融资项目合并生成还款计划；默认按季度还款，自动拆分每期本金与利息。
实际还款登记：从监管账户划出还款资金，录入实际还款金额、日期，核销对应还款计划，自动更新剩余本金与未还利息，同步更新下一月度最低留存额。
到期预警：提前 7/15 天推送待还款提醒，校验监管账户余额是否充足；余额不足触发资金补足预警。
放款、还款、利息计提数据同步 Oracle EBS 应付与总账模块，自动生成长期负债、利息计提与付款凭证。
3.7.4 资金池预测（核心新增）
3.7.4.1 预测基础数据
系统自动归集全量资金计划数据，作为预测基础：
资金流入项：租金收入计划（按合同计费周期）、融资放款计划（按批次放款节点）、供应商预付款退回计划、其他收入。
资金流出项：采购预付款计划、设备采购付款计划、融资还款计划（本金 + 利息）、运营费用支出计划、税费支出、保险费支出。
3.7.4.2 核心功能
多周期资金预测：支持按周、按月、按季度生成资金预测表，展示每期期初余额、本期流入、本期流出、期末余额。
预付款资金缺口测算：针对未来批次采购的预付款需求，自动测算存量资金（普通资金池可用余额）是否足以覆盖；若缺口为正，展示可正常支付；若缺口为负，自动触发融资预警，提示需启动银行 / 金租融资补齐。
多场景模拟：支持调整采购批次、付款节奏、融资放款时间，模拟不同场景下的资金余额变化，辅助资金决策。
预警规则配置：可设置资金安全线阈值，当预测期末余额低于安全线时，自动在首页工作台推送预警通知。
预测数据更新：实际业务发生后自动更新预测数据，支持手动调整预测参数。
预测结果可穿透查看明细构成，追溯每笔流入流出对应的业务单据。
3.7.5 收款管理
采用「收款登记 — 合同核销」双重管理模式。
收款登记：录入客户到账信息，区分入账账户（普通账户 / 监管账户），支持多币种，上传银行回单；支持待认领款项管理。
监管账户收款：登记后自动触发余额校验，比对月度最低留存额，生成可划转额度提示。
收款核销：支持一笔款项核销多合同 / 多批次 / 多台设备，也支持多笔款项核销一份合同 / 批次，精准匹配应收。
核销时自动计算汇兑损益。
核销完成后自动更新合同应收余额，同步 Oracle EBS 应收核销与资金模块。
3.7.6 资金池管理
分类展示：普通资金池余额、监管账户余额、资金池总余额、累计入金、累计出金。
资金流水台账：按来源、方向、项目、账户维度查询全量收付款记录，支持区分普通账户与监管账户流水。
收入构成分析：自有资金、银行流贷、金租放款等资金来源占比统计。
与 Oracle EBS 资金管理模块双向同步，保持资金数据一致。
3.8 资产与资源池管理
3.8.1 资产台账管理
单台设备对应单张固定资产卡片，强制绑定设备 SN、批次号、采购合同号、项目号、金租模式；可按项目、批次汇总资产原值、累计折旧、净值。
自动转固：单台设备进入「上架」节点时，根据金租模式自动判断资产权属，生成对应资产卡片或备查台账。
折旧计提：点亮验收后资产正式进入运营期，按月自动计提单台设备折旧，对应成本自动匹配租赁 / 转售收入；金租模式按准则对应折旧或租金成本核算。
资产全生命周期管理：从转固、折旧计提、运营维护到处置报废全流程跟踪。
资产退货联动：已转固设备发起退货，自动触发资产减少、折旧冲回，同步 Oracle EBS 固定资产模块。
支持资产卡片与设备、批次、采购合同、付款记录双向核对，确保账实一致。
3.8.2 资源池管理
实时展示各状态设备数量：在途、压测、可用、已占用。
设备上架自动计入可用资源，点亮验收自动扣减可用资源、计入已占用资源。
清晰标记资产权属：自购表内资产、金租表外资产、转售表外资源，确保资产负债表核算合规。
支持按型号、批次、项目维度查询资源占用情况。
3.9 发票管理
3.9.1 销售发票管理
支持多币种发票登记，录入发票号、开票日期、金额、税额、对应合同、批次、项目。
与收入确认完全解耦，支持先开票后确认收入、先确认收入后开票。
支持发票红冲，自动冲减对应开票记录与应收。
支持 OCR 识别快速录入。
发票信息同步 Oracle EBS 应收发票模块。
3.9.2 采购发票管理
（详见 3.3.4 采购发票管理）
3.10 对账中心
销售全链路对账：单合同维度对比合同总金额、累计收款、累计开票、累计确认收入，自动标记差异场景；支持穿透至批次、单台设备明细。
采购四单对账：采购合同、到货单、采购发票、付款单四单匹配校验，含预付款核销核对；支持按批次、单台设备核对。
资产交付对账：核对批次交付数量、单台设备数量与转固资产数量、点亮资产数量一致性。
监管账户对账：核对监管账户流水、租金收入、还款支出、最低留存额的合规性与数据一致性。
汇兑损益对账：核对外币单据汇率折算差异、汇兑损益入账准确性。
业财一致性对账：双向比对 SIEGPU 业务数据与 Oracle EBS 财务科目余额，涵盖应收、应付、资产、资金、损益全科目。
三流差异明细表：全域合同、发票、资金数据对比，支持按客户、供应商、期间筛选。

4.3 接口管理机制
同步方式：关键业务单据实时同步，批量数据支持定时同步。
触发机制：业务单据审核生效后自动触发同步；支持手动触发重传。
异常处理：同步失败自动记录失败原因，在首页工作台集中告警，支持单条 / 批量重试。
日志留痕：所有接口调用记录、请求参数、返回结果完整留存，支持审计追溯。
第五章 非功能需求
5.1 性能需求
常规页面响应时间≤2 秒，大数据量查询页面响应时间≤5 秒。
支持不少于 50 并发用户同时操作系统，无明显卡顿。
支持十万级单台设备数据、百万级单据数据存储与查询，资金预测模型计算时间≤8 秒。
5.2 数据一致性需求
业务数据与 Oracle EBS 财务数据保持口径一致，差异可定位、可追溯、可调整。
设备状态、资产状态、合同状态、资金余额变更时，关联模块数据同步更新，无数据不一致。
批次汇总数据与单台设备明细数据严格一致，监管账户余额与流水明细严格一致。
5.3 安全性需求
支持基于角色的权限管控，资金操作、监管账户操作、财务核算操作单独授权。
关键数据加密存储，敏感操作全程留痕。
支持账号密码策略、登录日志、异常登录拦截。
5.4 可扩展性需求
支持后续新增业务模式、金租产品、核算规则的配置化扩展，减少代码改造。
支持后续对接更多金融机构系统、银企直连系统。
支持设备规模扩容，满足未来业务量级增长。
5.5 易用性需求
界面简洁直观，关键操作路径不超过 3 步。
内嵌操作说明与字段提示，降低用户学习成本。
支持单据批量导入导出、批量节点操作，提升大规模设备管理效率。
第六章 合规与审计需求
核算合规：严格遵循企业会计准则（CAS）与租赁准则，收入确认、资产核算、汇兑损益、金租业务处理符合规范；收入模式判定依据全程留存，防范监管风险。
资金合规：监管账户资金留存规则严格执行，所有资金划转、预付款退回均有审批留痕，满足金融机构监管要求。
审计追溯：全流程操作日志、数据变更记录、接口同步日志完整保存，支持从报表追溯到合同、批次、单台设备、资金流水、财务凭证的全链路审计。
数据留存：业务单据、电子附件、日志数据按国家法规与公司制度要求期限留存。
变更留痕：合同、项目、主数据、设备批次、资金规则的所有变更均记录变更前后值、操作人、时间，不可删除与篡改。
附录：术语说明
点亮验收：指单台算力设备完成部署调试，客户验收通过并正式开始计费的节点。
总额法：按交易总额确认收入的核算方式，适用于承担主要责任人角色的业务。
净额法：按交易差价（服务费）确认收入的核算方式，适用于代理人角色的业务。
IRR：内部收益率，衡量项目投资收益水平的核心指标。
设备批次：由多台单台设备组合而成的批量管理单元，拥有唯一批次编号，用于提升批量作业效率。
直租：金融租赁公司出资采购设备并出租给我方，设备权属归金租公司，我方按期支付租金。
售后回租：我方将自有设备出售给金租公司后再租回，按期支付租金，到期可回购。
监管账户：金租项目专用资金账户，用于归集租金收入与支付租金还款，受金租机构监管，需满足最低留存额要求。
月度最低留存额：监管账户每月需保留的最低资金余额，计算公式为：季度还款金额 ÷ 3。
