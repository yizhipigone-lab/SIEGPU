总览系统是什么

SIEGPU 是一套算力租赁 ERP：把 GPU 服务器租给客户、走金融租赁融资、按「单台设备」计费折旧核算。系统把业务操作与财务核算串成一条流水线，并与 Oracle EBS 财务系统对接。

核心管理粒度

以单台设备为最小单元（唯一 SN），多台设备组合成批次批量作业，所有单据关联项目编号，实现「项目 → 批次 → 单台」三级追溯。

一条 11 步业务流水线

从立项 → 签合同 → 下订单 → 进设备 → 验收点亮 → 金租放款 → 按台计费 → 盈利测算，由 5 个角色接力完成，中间穿插财务总监审批。

管理员

ADMIN · 账号 admin
全局管理者：系统里唯一能看全部页面、并能调整流程配置、兜底异常的角色。

岗位职责

  • 维护全系统主数据与基础配置（供应商、客户、设备型号、银行账户）。
  • 掌握全局视野，可查看所有项目的业务与财务数据。
  • 兜底处理异常流程：可强制跳过或手动完成任意步骤（其他角色无此权限）。

管理员可访问全部 29 个页面，覆盖业务、财务、资产、对账全链路。以下是系统全部页面的逐一操作指引（本角色同时也是系统页面的「全量参考」）。

审批工作步骤 · 前后接缝

财务总监不占流水线某一步，而是穿插在关键节点把关：采购/销售验收、金租放款、开票核销、付款申请、收入确认等，均需总监审批后才生效。因此总监的「接缝」是——上游角色提交单据 → 总监审批 → 单据进入下一环节。

  1. 看待办：登录进入首页，待办中心显示「待审批」事项。
  2. 进审批中心：进入「付款管控 → 审批中心」，查看待审批申请列表。
  3. 审批：点「通过」放行，或点「驳回」并必填驳回原因（缺原因无法提交）。
  4. 收入确认审批：进入「收入确认」，审批草稿，通过后自动生成凭证并同步 EBS。

PROCUREMENT采购对接人

采

采购对接人

PROCUREMENT · 账号 buyer
业务起点：负责项目立项、两类合同与批次订单，流水线第 1–4 步。

岗位职责

  • 建立算力项目（项目编号、名称、业务类型、租赁模式等）。
  • 录入销售合同（与客户）与采购合同（与供应商）。
  • 下达批次订单（把多台设备组成批次下单）。

岗位工作范围

可访问 10 个页面：首页、项目总览、销售订单（公共），以及设备清单、项目、合同、订单、供应商、客户、设备型号（专属）。

在流水线中的位置（前后接缝）

步骤工作交接
1项目建立—（业务起点）
2销售合同—
3采购合同—
4批次订单完成后交给 → 项目交付负责人（进入设备导入）

工作任务与操作步骤

  1. 建立项目：进入「项目」页 → 新建项目，填项目编号、名称、业务类型（自有/直租/回租）、负责人、周期、预算。
  2. 录入销售合同：进入「合同」页 → 新建「销售合同」，关联项目与客户，录计费规则、核算判定信息（定价权/存货风险/主要责任人）。
  3. 录入采购合同：新建「采购合同」，关联项目与供应商，录采购明细（按台/按批次）、预付款比例、交付条款。
  4. 下达批次订单：进入「订单」页 → 新建批次订单，把待分组设备组成批次，关联采购合同与项目。

DELIVERY项目交付负责人

交

项目交付负责人

DELIVERY · 账号 delivery
交付中段：负责设备从导入到点亮验收，流水线第 5–8 步。

岗位职责

  • 导入设备清单（批量导入单台设备，生成 SN）。
  • 推进设备状态：到货 → 上架 → 点亮验收（单台或批量）。
  • 登记采购验收、销售验收。

岗位工作范围

可访问 9 个页面：首页、项目总览、销售订单（公共），以及设备清单、验收管理、客户确认、项目、设备型号、订单（专属）。

在流水线中的位置（前后接缝）

步骤工作交接
5设备导入从采购对接人接批次订单 → 导入设备
6设备到货—
7设备上架—
8点亮验收完成后交给 → 财务专员（进入金租放款/按台计费）

工作任务与操作步骤

  1. 导入设备清单：进入「设备清单」页 → 批量导入设备（关联批次、项目、型号、采购原值），系统自动生成唯一 SN。
  2. 设备到货：设备到达后，在设备详情推进状态到「到货」。
  3. 设备上架：压测通过后推进到「上架」（自动触发资产转固）。
  4. 点亮验收：客户验收通过后推进到「点亮验收」——计费起点，同时触发财产险投保、资产进入运营期。
  5. 验收登记：在「验收管理」页登记采购验收 / 销售验收，提交总监审批。

财务专员

FINANCE_STAFF · 账号 finance
财务收口：金租放款、按台计费、盈利测算 + 全部业财一体化功能，流水线第 9–11 步 + 全财务模块。

岗位职责

  • 金租放款：点亮达标后触发金租放款，登记放款与还款。

  • 盈利测算：生成项目盈利测算。
  • 全财务功能：发票、付款三重管控、进项税、收入确认、对账、汇率/汇兑损益、保险、预付款结转、退货财务联动、EBS 同步。

岗位工作范围

可访问 22 个页面（菜单最多），覆盖资金、发票、金租、计费、对账、收入确认、汇率、保险、预付款、付款、退货、EBS 等全部财务功能。
